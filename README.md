# 🎓 Admit Card Generator

A simple yet powerful tool to generate customized admit cards for students or exam candidates. Designed to streamline the admit card generation process using modern tools and a clean UI.

---

## 🚀 Features

- 🔧 Auto-generate admit cards based on student data
- 🖨️ Print-ready PDF export
- 🖼️ Custom layout with logo, photo, and personal details
- 📄 Supports bulk generation via Excel/CSV input
- 💡 Easy to customize design and data
